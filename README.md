# White Room Button

白い3D部屋を歩き、中央の赤いボタンを一度だけ押すミニゲームです。

## 遊び方

- スマホ: 左下の丸をドラッグして移動。画面右側をドラッグして視点を動かす。
- PC: `WASD` または矢印キーで移動。ドラッグで視点を動かす。
- 中央の赤いボタンに近づくと `PUSH` が有効になる。押すと上部のスコアが毎秒増え続ける。
- 右上の `↺` で最初からテストできる。

## APKの作り方（スマホだけで進める場合）

1. このフォルダをGitHubの新しいリポジトリに入れる。
2. GitHubの `Actions` で **Build Android APK** を実行する。
3. 終わったら実行結果の `Artifacts` にある `White-Room-Button-APK` をダウンロードする。

最初にダウンロードされるのはテスト用のdebug APKです。Google Playに出す段階では、署名付きrelease APK/AABに変える。
